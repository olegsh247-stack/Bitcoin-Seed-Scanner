# Bitcoin Seed Scanner

Простая программа, которая **ищет биткоины, которые современные кошельки часто не показывают** после восстановления seed — и позволяет их отправить.

Многие кошельки смотрят только на самый новый тип адресов. Старые монеты (особенно адреса на `3...`) могут «пропасть» из вида, хотя они по-прежнему в сети.  
Этот инструмент проверяет **все основные типы адресов сразу**.

> ⚠️ **Это не обычный кошелёк** для ежедневных платежей.  
> Используйте только для восстановления. Для крупных сумм — чистый компьютер или live-USB.

В самой программе есть переключатель **English · Русский · Español · Français** (справа вверху).

## Только официальный источник

Скачивайте **только** из этого репозитория:

**https://github.com/olegsh247-stack/Bitcoin-Seed-Scanner**

Копии с других сайтов или из мессенджеров могут быть изменены, чтобы украсть ваш seed.

### Проверка файла (по желанию, но полезно)

После сохранения `index.html` сверьте SHA-256:

```
efada0854c6cb29d0bd851b1381f6fc9519d51a80327087f72737cc9e2d72730
```

- **Linux / macOS:** `sha256sum index.html` (или `shasum -a 256 index.html`)
- **Windows (PowerShell):** `Get-FileHash index.html -Algorithm SHA256`

Если хеш не совпал — этот файл использовать нельзя.

*(Хеш нужно обновлять при каждом новом релизе `index.html`.)*

## Как скачать и открыть (1 минута)

### Способ 1 — самый простой

1. Откройте **https://github.com/olegsh247-stack/Bitcoin-Seed-Scanner**
2. Зелёная кнопка **Code** → **Download ZIP**
3. Распакуйте архив
4. Дважды кликните **`index.html`** — откроется в браузере

### Способ 2 — один файл

1. Откройте: **https://raw.githubusercontent.com/olegsh247-stack/Bitcoin-Seed-Scanner/main/index.html**
2. Правой кнопкой → **«Сохранить как…»**
3. Откройте сохранённый файл

Интернет нужен только чтобы проверить балансы и отправить транзакцию. Seed из браузера никуда не уходит.

## Как пользоваться

1. Вставьте **seed-фразу** (12 или 24 слова)
2. Введите **passphrase**, если использовали
3. Нажмите **Find coins / Найти монеты**
4. Дождитесь проверки всех типов адресов
5. Нажмите **Select / Выбрать** у адреса с балансом
6. Укажите получателя и сумму → **Prepare**
7. Введите **последние 6 символов** адреса получателя
8. **Sign and send / Подписать и отправить**

После работы закройте вкладку. На диск ничего не сохраняется.

## Что сканируется

| Тип адреса | Как выглядит | Путь |
|------------|--------------|------|
| Legacy | начинается на **1** | BIP44 |
| Nested SegWit | начинается на **3** | BIP49 |
| Native SegWit | начинается на **bc1q** | BIP84 |
| Taproot | начинается на **bc1p** | BIP86 |

Проверяются и receive, и change — каждая цепочка до **N подряд неиспользованных адресов** («gap limit», по умолчанию 25). Можно выбрать **номер аккаунта** (по умолчанию 0).

## Безопасность

- Seed и ключи только **в памяти браузера**
- Стираются при закрытии вкладки или «Clear»
- В сеть уходят только запросы к mempool.space (балансы, комиссии, broadcast). **Код с CDN не загружается**: все библиотеки встроены в `index.html`, а Content-Security-Policy разрешает странице только этот один скрипт и обращения к mempool.space.
- **Приватность:** для проверки балансов страница отправляет в mempool.space все производные адреса, поэтому сервис (и тот, кто видит ваше соединение) может связать эти адреса между собой и видит ваш IP. Если это важно — используйте Tor/VPN или собственную ноду.
- Если запрос баланса не удался (сеть, лимит запросов), программа сообщает об этом, а не пишет «монет нет». Увидев такое предупреждение, повторите сканирование.
- Перед отправкой нужно ввести последние 6 символов адреса
- **Не вводите seed на чужом или заражённом компьютере**
